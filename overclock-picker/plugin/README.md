## Optional Overclock Picker Plugin (for 1k, 2k, early 3k, go)

This is a lighter version of the experimental overclock using a lookup system over an array of predefined values for the PSP models prior to the Street and the last versions of the 3000 series.

Hold L + R to activate the picker, then use VOL+ or VOL- to increase or decrease the overclock value. An indicator in the top right corner shows how many steps you are targeting on the value table. To cancel the overclock, just decrease the value to 0.

## build & install

Build the plugin using the appropriate tools, then copy and paste `opicker.prx` into your SEPLUGINS folder.

## Overclock Picker and Tester

Before using this plugin, run the overclock picker to generate the required `.id` file.

## Note

The plugin is optional. You can use the overclock picker app on its own to enable, disable, or verify the overclock state on your device.
