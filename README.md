# Experimental PSP Overclock

## Description
This is an experimental project for technical purposes only, intended for developers and advanced users. Stability is not guaranteed, so use it with caution.

## Experimental Overclock With Automatic Ramp-Up
This project includes a plugin and a stress tester.  

See the [Experimental Overclock](experimental).  
Refer to its README for more information and credits.

## Overclock Picker
This is the latest overclock research done in this repository for the 1g, 2g, 3g and 5g models. It can also be used for the Street and the latest 3k models, but you will need to pick a table that exceeds 500 MHz in octable.h, since there is a frequency mapping incompatibility on these latest-generation machines when using this overclock technique.  

See the [Overclock Picker](overclock-picker).  
Refer to its README for more information.
